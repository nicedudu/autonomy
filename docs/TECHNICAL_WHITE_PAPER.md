# Autonomy 技术架构白皮书 (Technical White Paper)

## 1. 核心哲学：Agent 操作系统 (Agent OS)

Autonomy 是一个通用的自主智能体编排与执行引擎。它通过解耦认知、能力与环境，实现了一个领域无关的执行内核。用户只需下达宏观目标，系统将自主调度相关技能（Skills）达成任务。

## 2. 核心组件架构

### 2.1 任务编排器 (Orchestrator)
编排器是系统的“中央神经系统”，负责管理多步任务的流转。它维护一个“全局共识事实库 (Global Facts)”，确保不同节点在协作时信息同步。

### 2.2 通用执行器 (Universal Executor)
执行器负责驱动单个智能体节点的生命周期。它严格遵循以下闭环逻辑：
- **意图审计 (Intent Audit)**: 解析用户真实需求。
- **缺口分析 (Gap Analysis)**: 识别缺失的信息或能力。
- **单步执行 (Atomic Action)**: 通过 JSON RPC 发起工具调用。

### 2.3 技能管理系统 (Skill Manager)
基于 OpenAI Codex 标准，实现技能的动态发现与“渐进式披露”。技能包含元数据定义（YAML）与执行指令（Markdown）。

## 3. 通讯协议

系统强制执行结构化标签通讯：
- `<thought>`: 记录内部推理过程。
- `<plan>`: 记录动态任务账本。
- `<action>`: 记录工具调用指令。
- `<call>`: 记录跨节点委派请求。

## 4. 生产级特性

- **容错重试**: 对 LLM API 实施指数退避重试。
- **安全沙盒**: 内置 SSRF 防护与路径锁定逻辑。
- **透明化日志**: 所有的模型输入输出与工具交互均在控制台全量可见。
