# Autonomy 用户操作手册 (User Manual)

## 1. 快速上手

### 1.1 开启对话
在执行看板中输入你的目标（例如：“调研 2026 年新能源汽车趋势”）。主控节点会自动启动编排流程。

### 1.2 观察思考过程
点击消息气泡上方的“深度思考”，可以查看智能体当前的意图审计、计划安排以及正在激活的技能。

## 2. 核心功能说明

- **深度调研 (Researcher)**: 适用于需要多维度搜集信息并合成报告的复杂需求。
- **工具透传**: 即使主控节点没有现成答案，它也会调用搜索引擎为您寻找真实事实。

## 3. 常见问题 (FAQ)

**Q: 为什么智能体有时候会停止？**
A: 为保证安全与资源效率，单次任务默认限制在 15 轮推理内。如果任务未完成，它会输出阶段性总结。

**Q: 我可以自己添加新能力吗？**
A: 可以。请参考《通用智能体能力扩展框架 (Universal Agent Framework)》通过配置 SKILL.md 来添加。
