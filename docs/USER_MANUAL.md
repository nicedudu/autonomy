# Autonomy 产品使用手册 (用户版)

## 1. 欢迎来到 Autonomy

Autonomy 不是一个简单的聊天机器人，而是一个 **全自动化的数字高管团队**。在这里，你不再是“操作员”，而是 **董事长**。你只需下达战略目标，由 AI CEO (Mike) 带领其专家团队为你执行。

## 2. 核心团队成员

| 头像 | 姓名 | 职位 | 职责 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| 🦁 | **Mike** | **CEO (首席执行官)** | **团队大脑、任务总调度**。他负责理解你的意图，拆解任务，并指挥其他人干活。 | **默认对话对象**。当你不知道该找谁时，找 Mike。下达宏观指令，如“下季度利润提升20%”。 |
| 🔍 | **Alice** | **CPO (首席选品官)** | 市场洞察、爆款挖掘。 | 询问市场趋势、竞品分析、选品建议。 |
| 📦 | **Bob** | **SCM (供应链专家)** | 物流规划、成本核算。 | 询问运费计算、供应商筛选、库存周转。 |
| 📢 | **Carol** | **CMO (首席营销官)** | 品牌营销、广告投放。 | 生成广告文案、制定营销日历。 |

## 3. 如何与数字员工协作？

### 3.1 默认模式：CEO 负责制
在对话框中直接输入指令，无需指定人名。系统默认由 **CEO Mike** 接待。
*   **你输入**：“帮我分析一下最近宠物用品的市场趋势。”
*   **Mike (CEO) 回复**：“收到。这是一个典型的选品任务。@Alice (CPO)，请你调取北美市场的宠物用品数据...”
*   **Alice (CPO) 介入**：“好的 Mike。已检索到...”

### 3.2 定向呼叫模式 (@Mention)
如果你有非常具体、专业的问题，可以直接通过 `@` 符号呼叫特定专家，跳过 CEO 的调度。
*   **你输入**：“@Alice 这款猫砂盆在亚马逊上的竞品均价是多少？”
*   **Alice (CPO) 回复**：“目前 Top 10 竞品的均价为 $29.99...”

### 3.3 观察“思考过程”
我们的 AI 具备深度思考能力。在回复过程中，你可能会看到折叠的 **“智能体思考中...”** 区域。
*   点击展开，你可以看到 Agent 是如何拆解问题、搜索数据和进行逻辑推理的。
*   这有助于你判断 AI 决策的可信度。

## 4. 常见指令示例 (Quick Starts)

*   **全案策划**：“我有一款智能咖啡杯，想在 TikTok 上卖，帮我出一套方案。”（CEO 会自动调动 CPO 分析受众，CMO 写文案，SCM 算物流）
*   **单点突破**：“@Carol 帮我写 5 条适合圣诞节的促销文案，风格要幽默。”
*   **风险评估**：“@Bob 如果海运价格上涨 10%，我们的利润率还剩多少？”

## 5. 系统状态说明

*   **准备就绪**：团队已上线，随时待命。
